# Knowledge Map (Mappe di Conoscenza) — Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Editor di mappe di conoscenza (mind-map) dentro Ascend: pagina dedicata `/studio/mappe` con voce menu separata, nodi con testo editabile inline, collegamenti trascinabili tra nodi, persistenza nel DB centrale (nuova collezione `knowledgeMaps`, migrazione DB v10).

**Architecture:** React Flow (`@xyflow/react`) come motore editor (drag&drop, edge, zoom/pan già pronti e solidi) con styling custom Ascend (dark, bordi, glow accent). Una mappa = un record `{ id, name, nodes, edges, createdAt, updatedAt }` nella collezione `knowledgeMaps`. Elenco mappe a sinistra + editor a destra (layout master-detail). Salvataggio su ogni modifica (updateDB → saveDB → mirror sync-server) con debounce.

**Tech Stack:** Next.js (repo ASCEBT, la versione in `node_modules/next/dist/docs/` è autorevole — leggere la guida routing/client-components prima di scrivere), `@xyflow/react` v12, Tailwind (classi progetto: border-border, bg-elevated, text-accent…), storage esistente `useDB/updateDB/uid/nowISO` da `@/lib/storage`.

## Design decision (già confermate dall'utente)

1. **Collocazione:** pagina dedicata `/studio/mappe` + voce menu "Mappe" nel gruppo PERSONALE (accanto a Studio).
2. **Motore:** `@xyflow/react` v12 (React Flow).
3. **Scope MVP:** nodi con testo editabile inline + edge trascinabili (handle→handle). NIENTE auto-layout, niente export (possono arrivare in v2).
4. **Persistenza:** nuova collezione `knowledgeMaps` + migrazione DB v9→v10.
5. **Modelli di schema:** all creazione di una mappa si parte da un MODELLO — 3 built-in (Studio, Trading, Strategia) + i modelli PROPRI dell'utente ("Salva come modello" da qualsiasi mappa esistente). I modelli sono `KnowledgeMap` con `isTemplate: true` nella stessa collezione: nessuna collezione extra, merge già coperto.

**Step 1: tipi** — in `src/lib/types.ts`:

```ts
/** Mappe di conoscenza — nodo di una mind-map */
export interface KnowledgeNode {
  id: string;
  label: string;
  x: number; // posizione su canvas
  y: number;
  color?: string; // hex opzionale (default: accent)
}

/** Collegamento tra due nodi */
export interface KnowledgeEdge {
  id: string;
  from: string; // KnowledgeNode.id
  to: string;   // KnowledgeNode.id
}

/** Una mappa di conoscenza completa (isTemplate=true = modello riutilizzabile) */
export interface KnowledgeMap {
  id: string;
  name: string;
  nodes: KnowledgeNode[];
  edges: KnowledgeEdge[];
  isTemplate?: boolean; // true = modello selezionabile alla creazione (non appare come mappa normale... appare nella SEZIONE MODELLI)
  createdAt: string;
  updatedAt: string;
}
```

Nel DB interface aggiungere: `knowledgeMaps: KnowledgeMap[];` (dopo `studySubjects`, ~riga 357) e `export const DB_VERSION = 10;`

**Step 2: storage.ts** — tre punti:
1. `emptyDB()`: aggiungere `knowledgeMaps: [],`

```ts

  // v9 → v10: Mappe di conoscenza — nuova collezione `knowledgeMaps` vuota.
  out = { ...out, version: 10, knowledgeMaps: out.knowledgeMaps ?? [] };
}
```
3. `dedupeCollections()`: aggiungere `knowledgeMaps: dedupeById(db.knowledgeMaps),`

## Task 4 — Pagina `/studio/mappe` (master-detail)

**Objective:** elenco mappe + editor React Flow, CRUD mappa, salvataggio automatico.

**Files:**

**Struttura pagina** (`page.tsx`):
```
SectionHeader kicker="Personale · Studio" title="Mappe di conoscenza"
subtitle="Collega i concetti come in uno schema: nodi editabili e collegamenti trascinabili."
grid lg:grid-cols-[280px_1fr]:
  MapList (elenco mappe + bottone + Nuova mappa)
  KnowledgeEditor (mappa selezionata)
EmptyState se nessuna mappa selezionata
```

**KnowledgeEditor** (il cuore):
- `import { ReactFlow, Background, Controls, useNodesState, useEdgesState, addEdge, type Node, type Edge, Handle, Position } from "@xyflow/react";` + `import "@xyflow/react/dist/style.css";`
- Props: `{ map: KnowledgeMap; onChange: (m: KnowledgeMap) => void; }`
- Al mount/change di `map.id`: `setNodes(map.nodes.map(toRFNode))`, `setEdges(map.edges.map(toRFEdge))` (conversione KnowledgeMap → ReactFlow: nodo custom `type: "concept"` con Handle top+bottom+left+right `type="source"` E `type="target"` per collegamenti in ogni direzione).
- `nodeTypes = { concept: KnowledgeNodeCard }` (definito FUORI dal componente, altrimenti warning re-render).
- Doppio click su nodo → testo editabile inline (input dentro il nodo, Enter/blur conferma → aggiorna node.data.label → scheduleSave).
- Trascinamento handle→handle crea edge (onConnect → addEdge con id `uid()`, rimozione edge: click sull'edge seleziona → tasto Canc/Backspace; anche `DeleteKeyCode={["Backspace","Delete"]}`).
- Drag nodo → onNodesChange aggiorna x/y.
- Doppio click sul canvas → nuovo nodo centrato sul punto (label "Nuovo concetto", selezionato in edit).
- **Autosave debounced 800ms** su ogni modifica (nodes/edges/name): `onChange({ id, name, nodes: fromRFNodes(nodes), edges: fromRFEdges(edges), createdAt, updatedAt: nowISO() })`.
- Stile: `proOptions={{ hideAttribution: true }}` (progratis in v12 per app), Background variante dots color border, Controls stile dark via CSS custom nel componente (classi tailwind su wrapper: `[&_.react-flow__controls-button]:bg-elevated [&_.react-flow__controls-button]:border-border ...`).
- Toolbar minimale sopra il canvas: nome mappa (input inline), bottone "+ Nodo", bottone "Elimina mappa" (ConfirmDialog).

**KnowledgeNodeCard** (nodo custom):
- Card compatta: `rounded-xl border border-border bg-elevated px-3 py-2 text-[13px] font-medium shadow-[--shadow-card] focus:ring-accent`, max-w 200px, word-break.
- 4 Handle (Position.Top/Bottom/Left/Right) stile: `h-2.5 w-2.5 border-2 border-accent bg-elevated` (visibili su hover/selezione).
- Stato editing locale: doppio click → input autofocus; Enter/blur → commit label.
- Colore nodo: proprietà data.color con default accent;(v2: picker colori).

**MapList:**
- Due sezioni: **"Le tue mappe"** (`isTemplate` falso/assente, ordinate per updatedAt desc) e **"Modelli"** (con `isTemplate: true`).
- Sezione Modelli include 3 TEMPLATE BUILT-IN (creati al primo avvio se assenti, con `id` fissi `tmpl-studio`, `tmpl-trading`, `tmpl-strategia`):
  - **Schema Studio** (`tmpl-studio`): centro "Argomento" → figli "Concetti chiave", "Esempi", "Domande d'esame", "Collegamenti con altre materie"
  - **Schema Trading** (`tmpl-trading`): centro "Setup" → "Contesto di mercato", "Ingresso", "Stop loss", "Take profit", "Gestione posizione", "Journal note"
  - **Schema Strategia** (`tmpl-strategia`): centro "Obiettivo" → "Analisi", "Punti di forza", "Debolezze", "Azioni", "Rischi", "KPI"
  - I built-in NON sono eliminabili (bottone elimina nascosto); l'utente li può modificare.
- Ogni riga: Icon, nome, data aggiornamento, N nodi/N link, bottone elimina (ConfirmDialog, mai sui built-in).
- **"+ Nuova mappa"** apre un piccolo pannello di scelta: griglia di card modelli (i 3 built-in + i modelli utente con `isTemplate`) + card "Mappa vuota". Cliccare un modello crea una COPIA indipendente (`id: uid()`, senza `isTemplate`, nome "Copia di …") e la apre nell'editor.
- **"Salva come modello"** (bottone nella toolbar dell'editor, su mappe NON template): duplica la mappa corrente con `isTemplate: true` e la aggiunge alla sezione Modelli.
- I modelli utente eliminabili con conferma.

## Rischi / Note

1. **@xyflow/react in Next SSR:** il package è client-only → il file pagina deve avere `"use client"` (tutte le pagine del progetto lo sono già). Se compaiono warning di hydration, wrappare l'editor in `dynamic(() => import(...), { ssr: false })`.
2. **CSS di React Flow:** importarlo solo nel file del componente (Next lo code-splitta); i selettori dark si fanno con varianti tailwind arbitrary sul wrapper.
3. **Attribution:** `proOptions={{ hideAttribution: true }}` è consentito; verificare su v12.
4. **Conflitti merge multi-tab:** updatedAt su ogni salvataggio garantisce l'ultima scrittura vince (stessa semantica dei trade).
5. **Template built-in:** id fissi (`tmpl-*`) — se l'utente li modifica restano suoi (nessun re-seed che sovrascrive).
6. **v2 (non in questo piano):** colori/forme nodi, auto-layout raggiera, export PNG/JSON, link a sessioni di studio.
